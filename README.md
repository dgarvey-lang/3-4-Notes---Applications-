# 3-4 Notes Applications

An interactive review for Cost = Revenue (break-even) word problems, from the Lesson 4 Systems of Equations Applications notes. For each problem, students:

1. Define the variable (x = the number of items sold)
2. Choose the cost equation: Cost = initial expense + cost per item × number sold (wrong choices explain the mistake)
3. Choose the revenue equation: Revenue = selling price × number sold
4. Pick the best method: substitution (set Cost = Revenue), elimination, or graphing
5. Work it out: after setting Cost = Revenue and subtracting, fill in "initial expense = ___x". Students who chose graphing copy the two equations into Desmos and enter the point where the lines cross
6. Solve and interpret: the answer must be a whole number, and it always rounds UP

Open `index.html` in a browser (or enable GitHub Pages for this repository).

- Starts with the three examples from the notes (board games, rocking chairs, newsletters) plus a rounding-up problem based on the note slide
- Worked solutions that follow the notes, a check showing why rounding down still loses money, and a graph of the cost and revenue lines with the break-even point labeled
- Feedback for rounding down, leaving a decimal, adding instead of subtracting, and leaving out the per-item cost
- Links to the Desmos graphing calculator, with one-click copies of the equations to paste in
- A built-in whiteboard for each question, and a calculator that can paste its result into the answer box
- A summary of results by step, with extra practice problems generated for weak areas

Progress is saved in the browser's local storage.
